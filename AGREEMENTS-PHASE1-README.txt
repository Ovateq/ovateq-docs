OVATEQ DOCS — AGREEMENTS PHASE 1
Build date: 28 September 2026

DEPLOYMENT
1. Extract the ZIP.
2. Upload every extracted file and folder to the same GitHub Pages repository location currently used by Ovateq Docs.
3. Preserve the directory structure.
4. Commit the changes and allow GitHub Pages to deploy.
5. Open the site normally. The updated service worker refreshes existing app windows after activation.

IMPORTANT
- Do not upload the ZIP as a single website file. Extract it first.
- This package contains the complete current deployment, including Passport Photo Studio and converter assets.
- Agreement records are stored offline in the browser's IndexedDB database named "ovateq-agreements".
- Use Agreements > Export agreements backup before clearing browser/site data or moving to another device.
- Phase 2 AI is not included.

HOW TO OPEN AGREEMENTS
- Select the Agreements card under "Create a document", or
- Select the compact Agreements button near the lower-right edge of the application.

CORE CAPABILITIES
- Dynamic template fields and vehicle terminology
- Reusable individual/organisation party details
- Additional parties
- Interest, deposit, balance and installment calculations
- Draft through Completed/Disputed statuses
- Unique OVQ-AGR-YEAR-NNNNNN identifiers
- Save, reopen, edit, search and filter
- Witness and signature records
- Supporting attachments kept on device
- Important dates
- Version snapshot when an already Signed, Active or Completed record is changed
- Professional 14 pt Times New Roman-compatible print / Save PDF output
- Editable HTML download and device sharing
- JSON backup and restore
- Fully offline operation after installation

LEGAL PRESENTATION
The templates are practical first drafts. Land, property, ownership transfer, employment and other regulated transactions are marked for review. The product does not claim that a template, signature or payment replaces legal registration or statutory formalities.
